## ✨ Características Principales 

Esta PWA fue desarrollada como parte de la materia de Aplicaciones Web Progresivas y cuenta con las siguientes características implementadas:

* 📱 **Instalabilidad (App Shell):** Cuenta con un `manifest.json` válido que permite su instalación en Escritorio y Móviles como una aplicación nativa.

* ⚡ **Soporte Offline (Service Worker):** Gracias a `sw.js` y la estrategia *Cache First*, la aplicación sigue funcionando incluso sin conexión a internet.

* 🔔 **Notificaciones Push:** Implementación de la API de notificaciones para enviar alertas al sistema operativo del usuario.

* 📍 **Hardware Nativo (Geolocalización):** Integración con la API de `navigator.geolocation` para obtener las coordenadas del dispositivo gestionando correctamente los permisos.

* 🎨 **UI/UX Responsiva:** Interfaz construida con Bootstrap 5, asegurando un diseño adaptable y amigable.
